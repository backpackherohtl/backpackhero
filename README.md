# Backpack Hero Junior Company: Website

Ordnung, die mitgeht. Website der Backpack Hero Junior Company (Schulprojekt im Rahmen von Junior Achievement Austria, HTL Vöcklabruck).

- `index.html`: die komplette Website in einer Datei (Bild und Schrift sind eingebettet)
- `termine-vorlage.csv`: Vorlage für die Google-Tabelle mit den Verkaufsterminen

Gehostet über Netlify. Jede Änderung an `index.html` in diesem Repository geht automatisch online.
